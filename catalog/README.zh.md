# 标注分组目录，不是制造 BOM

`annotated_groups.json` 描述 66 个渲染 / 标注分组，并对应标准的源局部坐标几何。每项分别记录几何状态与材料、工艺、公差、实物配合状态；制造字段仍未验证。

对于 C001 / C002 等组件 ID，`geometry_path` 指向原组件或已有的顶点接缝恢复实体。完整 link 参考仍可能包含多个组件；`base_link__remaining` 是未识别内部几何，不是已确认的电控 BOM。`assembly/LABELS.md` 与中文译文对应海报名称。

未来制造 BOM 应明确独立物理料号、数量、材料工艺、紧固件以及版本兼容的采购件。不能将连通组件、STEP、标注或圆柱识别数量直接转换为采购数量。
