# 本地参考路径

原始 G-code 和执行日志不公开。`tools/slice_pilot_reference.py` 可在此重建检查用路径，Git 和公开清单会忽略它们。公开切片计数、估时和 G-code SHA256 位于 `printing/slicing_checks.json`；路径几何摘要仍在 `printing/`。
