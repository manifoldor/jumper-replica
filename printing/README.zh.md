# 六件首轮试装样件

仅为参考：通用直角坐标 FDM 220 × 220 × 250 mm，1.75 mm PLA，0.4 mm 喷嘴，0.2 mm 层高，请求三圈壁、15% 陀螺填充、顶底五层、Arachne；45° 自动贴合支撑，Z 间隙 0.2 mm、XY 间隙 0.3 mm、5 mm brim，喷嘴 205 °C / 热床 60 °C。实际打印机与材料尚未选定。

| 样件 | 含支撑参考 PLA | 参考普通模式时间 |
|---|---:|---|
| LF 肩壳 C001 | 6.98 g | 45 分 15 秒 |
| LF 肩壳 C002 | 9.22 g | 57 分 37 秒 |
| LM 小腿 C001 | 31.20 g | 3 小时 32 分 43 秒 |
| LM 小腿 C002 | 34.05 g | 3 小时 30 分 02 秒 |
| LM 足端 C001 | 5.81 g | 42 分 37 秒 |
| 上壳 C001 | 190.98 g | 18 小时 37 分 34 秒 |

各印一件，合计参考 278.24 g / 28 小时 05 分 48 秒，取决于参考运动配置。当前小腿方向的支撑约占总挤出材料一半；足端支撑很少。方向为试装起点，尚未优化工艺。

`oriented_stl/` 仅作刚体摆放，维持原尺度；`slicer/` 保存六个带配置 3MF、完整 INI。3MF 均已验证 CRC / 几何，并回读确认配置。`wall_samples/` 包含 18,000 个源坐标法线射线距离，并非最小壁厚认证。其余 JSON 分别记录几何、切片、路径边界及配置检查。

将 3MF 作为 PrusaSlicer 项目打开，绑定实际设备、耗材、温度、回抽、固件和起止程序，检查分层与支撑接触后重新切片。其他切片器可能忽略 Prusa 元数据。先印足端 / 肩壳，并填写[测量表](FIT_CHECKLIST.zh.md)。

公开仓库不含原始参考 G-code 和运行日志，保留切片摘要、路径检查结果与 G-code 哈希；脚本可在 `../experiments/reference_gcode/` 本地重建。实际打印前须配置设备起止程序。本次未发送打印任务；原材料、软垫柔性要求与承载性能仍待确认。
