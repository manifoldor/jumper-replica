# 装配参考与试装顺序

以源 link 名称为准。LF / RF 为左 / 右前，LM / RM 为左 / 右中，LR / RR 为左 / 右后；左右以机器人自身为准。前肢使用 J0–J4，行走腿使用 J0–J2。对应编号不代表相同轴方向或零位。

原组件局部齐次坐标 `p_mm` 通过 `geometry/parts_manifest.csv` 中的 `home_world_matrix_mm` 装配：`p_world_mm = H_home @ p_mm`。爆炸图再加上 `assembly/scene_manifest.json` 中的 `explosion_translation_mm`。爆炸偏移不能当实物配合矩阵。原 HOME 装配保留源位置及尚未解决的限位差异。

## 数字结构

- 机身：下壳 / 周向框架、内部安装板、内部托架、上壳及其他未识别内部件；显示 / 摄像头 / ToF 为模块参考。
- LF / RF：肩部、上臂、前臂、掌部与活动指；垫块和夹持嵌件保留源 f/b 后缀，不猜测其方位含义。
- LM / RM / LR / RR：髋部、大腿、小腿和足端垫。
- A/B 只是拆出的组件标识，不能自动推定内外或左右半壳。

源三角面足以展示链条与测量包络，但没有给出全部螺丝、轴承、摇臂、连接器针脚、走线或拧紧扭矩。

## 首轮实体试装

先印足端，再印 LF 肩壳两片。记录尺寸、拆支撑损伤、接缝合拢、螺柱对齐，以及与已确认实物舵机 / 摇臂的间隙。通过后再测 LM 小腿两片及端部接口。大上壳最后印，检查翘曲、筋 / 螺柱和主安装孔位。

使用 `printing/FIT_CHECKLIST.zh.md`，保存测量照片与局部修改毫米数；保留功能开口，维持整机原尺度。连接件承载与软垫材料工艺需实物确认；实测配合后再做单肢行程与载荷测试，目前尚未进行。
