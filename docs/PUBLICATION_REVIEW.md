# Publication review

Target repository: https://github.com/manifoldor/jumper-replica. This review covers the initial public snapshot.

Included: recovered mechanical geometry, editable assembly and figures, six pilot STL/3MF/profile sets, selected immutable upstream source, reproducible scripts and relevant engineering evidence.

Excluded: raw reference G-code, execution logs, internal agent instructions, local caches/environments, archives, vendor CAD without established redistribution terms, credentials and machine-specific paths. Large local outputs are reproducible and are not needed to use the public mechanical reference. Slicing summaries and G-code digests retain the record of reference checks.

The Blender file browser directory and embedded editor texts were cleared; render paths are relative. Offline validation scans all release files and 3MF entries for local home/temp paths and common credential markers, in addition to source hashes, geometry mappings, translation hashes and links. Pattern scanning cannot prove the absence of every conceivable private value; manual scope review accompanies it.

The Apache-2.0 LICENSE, upstream attribution and derivative-operation notices are retained. All physical-fit, material, tolerance, wiring and low-level-control gaps remain explicit. Publication does not change the experimental engineering status.
